# 対応範囲・未対応・既知の差

「再現」は、Igor Pro 8.04（Windows）で matplotlib の図と見比べて確認したものです（[verified.md](verified.md)）。
再現されないものは、`ExportReport.warnings` に必ず記録されます。

## 対応

| 区分 | 内容 |
|---|---|
| 線 | 実線。破線は、Igor の線種のうち破線パターンが最も近いものを選ぶ（線幅 1.5 で `--` → 11、`:` → 2、`-.` → 5）。Igor の破線の長さは絶対値、matplotlib は線幅に比例するので、線幅ごとに選ぶ |
| マーカー | `o s ^ v < > D d p h H * 8 + P x X _ \| .`。塗り・白抜き（透明）・白で塗った（不透明）を区別。`H * 8 P X` は近似（警告） |
| エラーバー | X・Y・XY、非対称、キャップの幅・太さ、色 |
| scatter | 単色・単一サイズ（円）。点ごとの色・サイズは最初の値を使う（警告） |
| 軸 | 線形・対数（目盛りラベルは 10ⁿ）、軸範囲（反転も）、グリッド（実線）、目盛りの向き、軸ラベル（mathtext の一部: 斜体の変数・上付き・下付き・ギリシャ文字） |
| 凡例 | 位置（`loc`）・枠・記号と文字。記号はグラフと同じ大きさ |
| 画像 | `imshow`（2 次元スカラー、`origin`・`extent`）、`pcolormesh`（矩形格子。均一・不均一）、`Normalize`・`LogNorm`、NaN・マスク、colormap の忠実な再現（256 色の Wave）または Igor の色テーブル |
| カラースケール | 縦向き。既定はプロットの右の枠つきの箱。`cs_mode="mpl"` で matplotlib のカラーバーに合わせる。対数カラー対応 |
| 等高線 | `contour`（単色・colormap の線、`clabel` のラベル）、`contourf`（塗り）。**元の Z 行列から** Igor の等高線（`AppendMatrixContour` / `ModifyContour`）にする。画像に重ねられる |
| レイアウト | ウィンドウ・余白・プロット領域・文字サイズ・フォントを明示して固定。軸ラベルは `lblMargin` で、目盛りラベルと重ならない位置に置く |

## 未対応（警告つきで代替・スキップ）

- `alpha`（無視）、複数の Axes（最初の 1 つだけ）、タイトル、テキスト注釈、`fill_between` などの塗り、`LineCollection`（`hlines/vlines`）。
- RGB 画像、非矩形メッシュ、`gouraud`、`pcolor`、`LogNorm` 以外の非線形 Norm（線形にする）、横向きカラーバー（縦向きにする）、`symlog` などの軸（線形にする）。
- 等高線: レベルごとに異なる色のリスト（`colors=[…]`）→ 最初の色、負のレベルの破線 → 実線、等高線のカラーバー、矩形でない格子、matplotlib 3.8 未満。
- 複数列の凡例（`ncol`）は 1 列になる。凡例の errorbar 記号は、Igor ではマーカーだけ。
- 2 軸グラフ、複数パネル。

## 既知の差（直さない）

- 対数軸の副目盛りのラベル（2, 4, 6, 8）は Igor の既定のまま。
- 目盛りの刻み、凡例の細かい位置、フォントのアンチエイリアスは一致しない。
- `contourf` の色は近似（Igor は各帯をレベルの下端の色で塗る。半帯ぶんずらして合わせている）。最低レベルより下の領域も最低レベルの色で塗られる。画像に重ねるなら線を使う。
- `*`（五芒星）は Igor の四芒星で描く。

## 「一致」の基準

画素単位の同一ではなく、次の一致を見ます: データの位置、軸範囲と対数、色、線幅、マーカー（形・大きさ）、エラーバー（キャップ含む）、凡例の文字と位置、ラベル、画像の向きと色範囲、ウィンドウとプロット領域の大きさ。`tools/audit.py` が、送った命令と Igor の読み戻し（`igor_audit.txt`）を照合します。
